# v0.1.0 — The Slave Pit (vertical slice)
The first playable release: the Gate 2 vertical slice. One gladiator (The Nobody) and one arena (the Slave Pit), ending in a boss fight with Gorm, the Pit Master. A run lasts about 10 minutes.

## Downloads
| File | Platform | Notes |
|---|---|---|
| `Gladiator-v0.1.0-linux.tar.gz` | Linux x86_64 | Extract it, then run `./Gladiator.x86_64`. |
| `Gladiator-v0.1.0-windows.zip` | Windows 10/11, 64-bit | Extract it, then run `Gladiator.exe`. SmartScreen may warn about an unknown publisher: choose **More info → Run anyway**. |
| `Gladiator-v0.1.0-macos.zip` | macOS (Intel and Apple silicon) | Unzip it and move `Gladiator.app` anywhere. The app isn't notarised, so the first time, **right-click → Open → Open**. If macOS still says the app is damaged, run `xattr -cr Gladiator.app` in Terminal. |
| `Gladiator-v0.1.0-linux-dev.tar.gz` | Linux x86_64 | The same game plus the **F1 admin menu**: God mode, % buffs, jump the timer, spawn enemies. |

**Tested:** Linux, with a 10-minute bot run and a smoke run of this exact archive. The Windows build was smoke-run under Wine on Linux (Direct3D 11, 40 s bot run, no errors), not yet on real Windows. The macOS build is a universal app (Intel and Apple silicon) that nobody has run on a Mac yet. Please report anything that breaks.

## What's in it
- **The run:** main menu → choose your gladiator → 8 minutes of survival in the Slave Pit → Gorm → victory or death → summary.
- **Enemies:** six types (Convict, Pit Cur, Shield Thug, Slinger, Brute, Fire-Pot Thrower) and three elite modifiers (Armored, Fast, Explosive). A spawner ramps them up to 300 on screen.
- **Your build:** four weapons with different attack patterns (Gladius, Spear, Javelins, Chakram) and 18 Boons (passive upgrades). Burn, Bleed, Shock and Slow combine into synergies.
- **Level-up cards:** reroll, banish and skip.
- **In the arena:** chests (they cost gold) and the Blood Altar (trade max HP for a Rare card).
- **Gorm, the Pit Master:** two phases, four telegraphed attacks and guard waves. In phase 2 he sets the fence on fire.
- **Progression:** a save file and Renown (a score that grows each run). The Codex screen shows your records and unlocks. Beating Gorm unlocks **Gorm's Flail**, a weapon of spiked balls that circle you.
- **Polish:** placeholder sound effects, a crowd that reacts to your kills, a kill-streak announcer and an options menu (volumes, look sensitivity, FOV, screen shake, render scale).

## Controls
Move with WASD or the left stick and look with the mouse or the right stick. Space / South button jumps. Shift / East button / LT slides. E / North button opens chests. Pick cards with 1–4. R rerolls, B banishes, X skips. Esc pauses; from the pause screen, O opens Options.

## Known issues
- All sounds are synthesised placeholders.
- Gorm's fight length varies a lot with your build.
- Your save is stored at:
  - Linux: `~/.config/unity3d/SoloDev/Gladiator`
  - Windows: `%USERPROFILE%\AppData\LocalLow\SoloDev\Gladiator`
  - macOS: `~/Library/Application Support/SoloDev/Gladiator`

  Delete `save.json` there to start over.
