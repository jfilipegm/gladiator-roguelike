# v0.11.0 — The Thunder Champion
A fifth gladiator: a bronze champion whose spear throws lightning through the crowd. Beat the Beast Lord to unlock him.

## Downloads
| File | Platform | Notes |
|---|---|---|
| `Gladiator-v0.11.0-linux.tar.gz` | Linux x86_64 | Extract it, then run `./Gladiator.x86_64`. |
| `Gladiator-v0.11.0-windows.zip` | Windows 10/11, 64-bit | Extract it, then run `Gladiator.exe`. SmartScreen may warn about an unknown publisher: choose **More info → Run anyway**. |
| `Gladiator-v0.11.0-macos.zip` | macOS (Intel and Apple silicon) | Unzip it and move `Gladiator.app` anywhere. The app isn't notarised, so the first time, **right-click → Open → Open**. If macOS still says the app is damaged, run `xattr -cr Gladiator.app` in Terminal. |
| `Gladiator-v0.11.0-linux-dev.tar.gz` | Linux x86_64 | The same game plus the **F1 admin menu**. |

**Tested:** Linux: the full test suite, and two 10-minute bot runs as the Thunder Champion on the dev build (the Provincial Pit and the Stone Amphitheater), with no errors. They held 397 and 394 fps on average, and 206–217 fps with 250+ enemies, and the bot beat the Champion and the Beast Lord. The Windows build is smoke-run under Wine on Linux, not on real Windows. The macOS build is a universal app (Intel and Apple silicon) that nobody has run on a Mac yet. Please report anything that breaks.

## What's new
- **The Thunder Champion** (unlocked by beating the Beast Lord in the Stone Amphitheater):
  - **Looks:** bronze armour, a storm helm with a big lightning-bolt crest, a blue cape, and a spear held upright. 90 HP, a little faster than the Nobody.
  - **Storm Spear:** lightning leaps from the spear to the nearest enemy (up to 9 m away), then jumps on to the next one within 5 m, three more times. Everything it strikes is **Shocked** and takes more damage from everything else.
  - **Stormcaller:** every enemy you hit adds a Charge, +1.5 % attack speed each, up to +60 %. Stop hitting things for 2.5 s and it drains away. The bar under your health shows it.
  - **Lightning Dash:** start a slide when the dash is ready (every 3 s) and you blink up to 7 m, hitting and Shocking everything on the way. Walls stop the blink.
  - The Storm Spear also joins everyone's level-up pool.

## Known issues
- **The Thunder Champion is fragile on purpose**, and against a single big target (a boss) the lightning has nowhere to jump. Tell me if he's fun or just frustrating.
- On the Storm Spear's level-up cards, "+1 Pierce" means one more jump.
- Sounds are still placeholders made in code, as before.
