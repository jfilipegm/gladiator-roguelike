# v0.12.0 — The Golden Idol
A sixth gladiator: a champion so rich he had himself gilded. The more gold he carries, the harder he hits. Earn 10,000 gold over all your runs to unlock him.

## Downloads
| File | Platform | Notes |
|---|---|---|
| `Gladiator-v0.12.0-linux.tar.gz` | Linux x86_64 | Extract it, then run `./Gladiator.x86_64`. |
| `Gladiator-v0.12.0-windows.zip` | Windows 10/11, 64-bit | Extract it, then run `Gladiator.exe`. SmartScreen may warn about an unknown publisher: choose **More info → Run anyway**. |
| `Gladiator-v0.12.0-macos.zip` | macOS (Intel and Apple silicon) | Unzip it and move `Gladiator.app` anywhere. The app isn't notarised, so the first time, **right-click → Open → Open**. If macOS still says the app is damaged, run `xattr -cr Gladiator.app` in Terminal. |
| `Gladiator-v0.12.0-linux-dev.tar.gz` | Linux x86_64 | The same game plus the **F1 admin menu**. |

**Tested:** Linux: the full test suite, and two 10-minute bot runs as the Golden Idol on the dev build (the Slave Pit and the Stone Amphitheater), with no errors. They held 372 and 505 fps on average, and 184–214 fps with 250+ enemies, and the bot beat the Beast Lord. The Windows build is smoke-run under Wine on Linux, not on real Windows. The macOS build is a universal app (Intel and Apple silicon) that nobody has run on a Mac yet. Please report anything that breaks.

## What's new
- **The Golden Idol** (unlocked by earning 10,000 gold over all your runs; if you already have, he's waiting at the next main menu):
  - **Looks:** gilded from head to toe, a golden mask, and a huge spiked sun-crown behind his head. 100 HP.
  - **Coin Toss:** he flicks gold coins at the three nearest enemies; each one goes through the first enemy it hits.
  - **Midas Body:** +1 % damage for every 10 gold you're carrying, up to +100 % at 1,000 gold. Spending gold spends your power, so every chest is a real choice. The bar under your health shows the bonus.
  - **Golden Streak:** the announcer's kill streaks pay more gold for 8 s: ×1.5 for a Killing Spree, up to ×3 for Unstoppable.
  - **Make It Rain:** start a slide with at least 40 gold (every 2 s) and you pay 40 to spray 16 coins all round you.
  - The Coin Toss also joins everyone's level-up pool.
