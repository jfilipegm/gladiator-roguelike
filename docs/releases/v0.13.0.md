# v0.13.0 — The Ashen Oracle
A seventh gladiator, and a secret to find: a masked seer whose curses spread through the crowd. To unlock him, you'll have to meet someone in the Stone Amphitheater.

## Downloads
| File | Platform | Notes |
|---|---|---|
| `Gladiator-v0.13.0-linux.tar.gz` | Linux x86_64 | Extract it, then run `./Gladiator.x86_64`. |
| `Gladiator-v0.13.0-windows.zip` | Windows 10/11, 64-bit | Extract it, then run `Gladiator.exe`. SmartScreen may warn about an unknown publisher: choose **More info → Run anyway**. |
| `Gladiator-v0.13.0-macos.zip` | macOS (Intel and Apple silicon) | Unzip it and move `Gladiator.app` anywhere. The app isn't notarised, so the first time, **right-click → Open → Open**. If macOS still says the app is damaged, run `xattr -cr Gladiator.app` in Terminal. |
| `Gladiator-v0.13.0-linux-dev.tar.gz` | Linux x86_64 | The same game plus the **F1 admin menu**. |

**Tested:** Linux: the full test suite, and two 10-minute bot runs as the Ashen Oracle on the dev build (the Slave Pit and the Stone Amphitheater), with no errors. They held 464 and 479 fps on average, and 210–258 fps with 250+ enemies, and the bot beat Gorm and the Beast Lord. The Windows build is smoke-run under Wine on Linux, not on real Windows. The macOS build is a universal app (Intel and Apple silicon) that nobody has run on a Mac yet. Please report anything that breaks.

## What's new
- **The Ashen Oracle** (a secret unlock: see below):
  - **Looks:** a hunched figure in an ash-grey robe, a bone mask with glowing purple cracks, and a crooked staff with a censer hanging from it. 85 HP.
  - **Ashen Censer:** he lobs a smoking orb into the thickest crowd. It bursts, **Curses** everything it hits, and leaves a cursed patch on the ground for 3 s that keeps cursing whatever walks in.
  - **Curse**, a new status: purple damage over time that stacks.
  - **Contagion:** a cursed enemy that dies bursts, hurting everything around it and passing the curse on. The horde does his killing for him.
  - **Smoke Veil:** the first hit he takes every 5 s makes smoke explode out of him: everything close is Cursed, Slowed and pushed back.
  - The Ashen Censer also joins everyone's level-up pool.
- **A new secret in the Stone Amphitheater.** On some runs, partway through, someone you don't know is waiting on the sand. Find out what he wants.
