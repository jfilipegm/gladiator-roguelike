# v0.21.0 — The Editor's Edicts
Make the games harder for more Renown: eleven Edicts, decrees you can turn on before a fight. Chests, gifts and whims also no longer repeat from run to run.

## What's new
- **Edicts.** Once you've beaten Gorm, the arena screen gets an **EDICTS** button (or **E** / the gamepad's **Y**). Each edict is a handicap that raises the run's Renown, win or lose; turn on as many as you dare (three at +20 % each pay ×1.6). Your choice is remembered between runs.
  - **Free once Gorm falls:** Iron Hides (enemies +50 % HP, bosses +25 %), The Hungry Horde (+30 % enemies), Blood Sport (you take +40 % damage).
  - **In the Market (150 Renown each):** Glass Jaw (max HP ×0.6), Swift Foes (enemies +15 % speed), Empty Purses (half the gold, dearer chests), A Fickle Crowd (Favor fills at half speed, the crowd bores twice as fast).
  - **Earned by winning under edicts:** Meagre Choices (one card fewer, no rerolls), The Impatient Emperor (the horde comes a third sooner), Champions' Day (elites twice as often), No Mercy (no healing at all).
  - The active edicts show as icons under the timer, on the arena tablet and on the end screen, where the Renown line shows the multiplier. The Codex lists them under Challenges and Market, and Records has "Most edicts in a win".
- **Every run is different now.** Chests and the altar used to appear in the same places in the same order every run of an arena, and the crowd's gifts and the Arena Master's whims came in the same order. Each run started from the menu now gets its own.
