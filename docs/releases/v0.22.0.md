# v0.22.0 — The Daily Games
One fixed fight a day, the same for everyone with the same unlocks, and a seed for every run.

## What's new
- **The Daily Games.** Once you've beaten Gorm, the main menu gets a **DAILY** button. Each day (midnight UTC) the Editor proclaims one fight: an arena and a gladiator from those you've earned, two edicts, and one seed. Your first attempt of the day is **scored**: ×1.5 Renown on top of the edicts, and a line in the daily ledger (your last seven are on the Daily screen). Later attempts that day are practice. A gold dot on DAILY means today's scored attempt is still open; a clock says when the next one comes.
- **Two new challenges:** Daily Bread (play 3 scored dailies, +100 Renown) and Champion of the Day (win a scored daily, +150).
- **Every run has a seed**, shown on the end screen and the pause page ("SEED 7F3A-91C2"). **SAME SEED** replays it: the same chests in the same places, the same swarms from the same sides, the same elites, the same cards for the same choices, the same gifts and whims. **RETRY** draws a fresh seed.
- The Codex's Records count your dailies played and won.

## Known issues
- A seed replays the run's events, not your play: which enemy spawns when, crits and gold drops still depend on what you do.
- The daily's numbers (×1.5, two edicts) are first guesses.
- Sounds are still placeholders made in code, as before.
