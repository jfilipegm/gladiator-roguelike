# v0.23.0 — Skins
Two new looks for every gladiator: twenty skins, one to buy with Renown and one to earn by winning with him.

## Downloads
| File | Platform | Notes |
|---|---|---|
| `Gladiator-v0.23.0-linux.tar.gz` | Linux x86_64 | Extract it, then run `./Gladiator.x86_64`. |
| `Gladiator-v0.23.0-windows.zip` | Windows 10/11, 64-bit | Extract it, then run `Gladiator.exe`. SmartScreen may warn about an unknown publisher: choose **More info → Run anyway**. |
| `Gladiator-v0.23.0-macos.zip` | macOS (Intel and Apple silicon) | Unzip it and move `Gladiator.app` anywhere. The app isn't notarised, so the first time, **right-click → Open → Open**. If macOS still says the app is damaged, run `xattr -cr Gladiator.app` in Terminal. |
| `Gladiator-v0.23.0-linux-dev.tar.gz` | Linux x86_64 | The same game plus the **F1 admin menu**. |

**Tested:** Linux: the full test suite, plus bot runs in skins. The Windows build is smoke-run under Wine on Linux, not on real Windows. The macOS build is a universal app (Intel and Apple silicon) that nobody has run on a Mac yet. Please report anything that breaks.

## What's new
- **Skins.** On the select screen, a strip under your gladiator shows his looks: **CLASSIC** and two skins. **Q / E** (or the arrows, or **LB / RB**) cycle through them; the one you own is worn at once, and the next fight uses it, the daily included.
  - **One skin each in the Market:** 250 Renown for the Nobody, the Pit Goblin and the Blood Knight; 350 for the others. **BUY** on the strip (or **F** / the gamepad's **Y**), or in the Codex Market.
  - **One skin each for champions:** win 3 runs with that gladiator. The strip shows your progress.
  - Skins change only how he looks: same shape, same weapon, same stats.
  - The roster tile shows the skin you wear; the Codex names the skin a Market item or challenge gives.
- The select screen's model goes back to the Nobody when you pick him again (it kept the last gladiator shown).
