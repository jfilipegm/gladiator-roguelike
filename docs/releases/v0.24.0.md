# v0.24.0 — The Roman look
A new face for every screen: Roman lettering, frames in bronze, marble, wax and mosaic, and an announcer banner that drops like a curtain.

## Downloads
| File | Platform | Notes |
|---|---|---|
| `Gladiator-v0.24.0-linux.tar.gz` | Linux x86_64 | Extract it, then run `./Gladiator.x86_64`. |
| `Gladiator-v0.24.0-windows.zip` | Windows 10/11, 64-bit | Extract it, then run `Gladiator.exe`. SmartScreen may warn about an unknown publisher: choose **More info → Run anyway**. |
| `Gladiator-v0.24.0-macos.zip` | macOS (Intel and Apple silicon) | Unzip it and move `Gladiator.app` anywhere. The app isn't notarised, so the first time, **right-click → Open → Open**. If macOS still says the app is damaged, run `xattr -cr Gladiator.app` in Terminal. |
| `Gladiator-v0.24.0-linux-dev.tar.gz` | Linux x86_64 | The same game plus the **F1 admin menu**. |

**Tested:** Linux: the full test suite, plus bot runs. The Windows build is smoke-run under Wine on Linux, not on real Windows. The macOS build is a universal app (Intel and Apple silicon) that nobody has run on a Mac yet. Please report anything that breaks.

## What's new
- **Four fonts:**
  - **Luckiest Guy** for numbers: damage, the timer, gold, kills, prices.
  - **Caesar Dressing** for the announcer: banners, LEVEL UP!, VICTORY!.
  - **Marcellus SC** for names, headers and buttons.
  - **Marcellus** for descriptions.
- **Frames drawn for the game:**
  - Buttons are bronze or marble plaques with dovetail handles (tabula ansata). Bronze is a screen's main action, marble the rest.
  - The HUD and the level-up stats sit on bronze, the pause page on marble, run stats and tablets on wax.
  - Proclamations sit in a mosaic, gladiators on scutum shields, and meander bands sit under headers.
- **The announcer banner (vexillum).** Swarms, elites and the Arena Master's whims drop a crimson banner from the top of the screen. It sways, holds about two seconds and rolls back up. The boss's entrance and phases use a purple banner. Streaks and the crowd's lines stay short callouts.
- **The level-up screen (layout A).** Smaller cards (300×520), centred with the title and the Reroll / Banish / Skip buttons; your stats sit in the right margin.
  - Each card keeps its animated 8-bit icon with its rarity-coloured outline, inside a stone, bronze, silver or gold frame. The card you have selected gets a thin glow in its rarity colour.
  - A Legendary has a laurel wreath behind its icon.
  - The boss's reward now reads **SPOILS OF VICTORY**.
- **The end screen.** YOU DIED hangs on a crimson banner; SURVIVED! and VICTORY! stand between laurel branches; the run's numbers are on a wax tablet.
- The HUD timer steps aside while you choose a card, and the announcer banner hides while the game is paused.
- **The menus.** The main menu, the gladiator select (scutum tiles, a wax tablet), the arena ladder, the Edicts page, the Daily Games, the Codex and the options all wear the new look.
- The font licences ship with the game in `StreamingAssets/Licenses/Fonts` (see `docs/CREDITS.md`).

## Known issues
- **This is a first pass at the look.** Tell me what to change: sizes, colours, which frame goes where, the banner's timing (it's all tunable).
- The laurel branches beside VICTORY! are drawn small and scaled up, so they look chunky at that size.
- Sounds are still placeholders made in code, as before.
