# v0.27.0 — The new look
Every character in the game is redrawn in the style you picked (lineup variant A): chibi proportions, simple chamfered shapes, flat-shaded facets, readable faces. Same gameplay, same hitboxes, same animations.

## Downloads
| File | Platform | Notes |
|---|---|---|
| `Gladiator-v0.27.0-linux.tar.gz` | Linux x86_64 | Extract it, then run `./Gladiator.x86_64`. |
| `Gladiator-v0.27.0-windows.zip` | Windows 10/11, 64-bit | Extract it, then run `Gladiator.exe`. SmartScreen may warn about an unknown publisher: choose **More info → Run anyway**. |
| `Gladiator-v0.27.0-macos.zip` | macOS (Intel and Apple silicon) | Unzip it and move `Gladiator.app` anywhere. The app isn't notarised, so the first time, **right-click → Open → Open**. If macOS still says the app is damaged, run `xattr -cr Gladiator.app` in Terminal. |
| `Gladiator-v0.27.0-linux-dev.tar.gz` | Linux x86_64 | The same game plus the **F1 admin menu** (spawn any enemy to look at it). |

**Tested:** Linux: the full test suite (301 EditMode, 427 PlayMode), a 300-enemy stress run, and in-run captures. The Windows build is smoke-run under Wine on Linux, not on real Windows. The macOS build is a universal app (Intel and Apple silicon) that nobody has run on a Mac yet. Please report anything that breaks.

## What's new
- **The whole cast in the new style:**
  - all 11 gladiators, the Wolf and the Bookmaker;
  - the 18 enemies;
  - the 6 bosses and the Chimera;
  - all 20 skins;
  - the select-screen portraits and the codex pictures.
- **Faster with big crowds.** Each character is now drawn in 6 pieces instead of 20–90. At 300 enemies the game ran at 336 fps instead of 181 on the test PC: frame time 2.98 ms instead of 5.52, and the slowest frames 4.0 ms instead of 10.7.
- **The old look is kept in the project.** One menu item in the Unity Editor switches every model back if a character reads worse.

## What to look at
- Each gladiator on the select screen, and in a run: running, swinging, getting hit.
- The enemies in a crowd: can you still tell them apart at a glance? The enemy colour patches are still there.
- The bosses' special moves still play: Gorm's flail, the Beast Lord's spear, the Emperor's eagle wings and the Eternal Victor's falx throw.
- The artists' own doubts:
  - the Bookmaker's quill can read as a blade;
  - Asterion's snout looks pig-like from the front;
  - the Brute's head sits on his shoulders;
  - the Centurion's crest looks like a red umbrella;
  - Gorm's beard looks like a bib;
  - the Beast Lord's front is busy;
  - the Skeletal Legionnaire's helmet looks like a cap.

## Known issues
- The joints are rigid parts, as before: an arm turns at the shoulder as one piece.
- Sounds are still placeholders made in code, as before.
