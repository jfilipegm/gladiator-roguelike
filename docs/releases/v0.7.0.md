# v0.7.0 — Secrets and Challenges
Every run now moves something forward. Challenges give you goals to chase, secrets hide in both arenas, and the Renown you've been earning finally buys something. A new Codex keeps track of all of it.

## Downloads
| File | Platform | Notes |
|---|---|---|
| `Gladiator-v0.7.0-linux.tar.gz` | Linux x86_64 | Extract it, then run `./Gladiator.x86_64`. |
| `Gladiator-v0.7.0-windows.zip` | Windows 10/11, 64-bit | Extract it, then run `Gladiator.exe`. SmartScreen may warn about an unknown publisher: choose **More info → Run anyway**. |
| `Gladiator-v0.7.0-macos.zip` | macOS (Intel and Apple silicon) | Unzip it and move `Gladiator.app` anywhere. The app isn't notarised, so the first time, **right-click → Open → Open**. If macOS still says the app is damaged, run `xattr -cr Gladiator.app` in Terminal. |
| `Gladiator-v0.7.0-linux-dev.tar.gz` | Linux x86_64 | The same game plus the **F1 admin menu**. |

**Tested:** Linux: the full test suite, and a 10-minute bot run in each arena on the dev build, with no errors. Both held 188–199 fps with 250+ enemies. In the Provincial Pit the bot beat the Champion, which unlocked the Net and two challenges. The Windows build is smoke-run under Wine on Linux, not on real Windows. The macOS build is a universal app (Intel and Apple silicon) that nobody has run on a Mac yet. Please report anything that breaks.

## What's new
- **The Codex, rebuilt.** Seven tabs: Records, Gladiators, Arsenal, Bestiary, Challenges, Secrets, Market.
  - Every enemy, weapon, Boon, evolution and synergy is in it.
  - Anything you haven't found yet is a black silhouette or "???", with a hint.
  - New entries are marked **NEW**, and the menu's CODEX button counts them.
  - **Controls:** Left/Right (or the shoulder buttons) change tab, Up/Down change page.
- **Challenges** are goals with a progress bar. Some unlock content, some pay Renown:

  | Challenge | Goal | Reward |
  |---|---|---|
  | Pit Master's Bane | Defeat Gorm 3 times | **Gorm's Whip** |
  | Champion of the Provinces | Defeat the Provincial Champion | **the Net** |
  | First Evolution | Evolve a weapon | +100 Renown |
  | Synergist | Switch on 3 different synergies (over any runs) | +150 Renown |
  | Butcher of the Pit | Kill 5,000 enemies in one run | +100 Renown |
  | Every Gladiator Wins | Win with the Nobody, the Goblin and the Knight | +200 Renown |
- **Two new secrets.** The Codex hints at them; we won't spoil them here. One lives in each arena. Both repeat for gold once you've found them.
- **The Market.** Spend Renown in the Codex: **Winged Sandals** (a jump in mid-air), **Wax Tablet** (more XP and rerolls) and **Gilded Palm** (more gold, longer reach), 300 each.
- **Three new weapons:**
  - **Sling:** a stone at the *farthest* enemy in reach, with big crits.
  - **Net:** a slow, wide throw that pins everything it lands on.
  - **Gorm's Whip:** a long, thin crack through a line. The tip always crits, so fight at whip's length.
- **Three new synergies**, completed by the new Boons:
  - **Whirlwind** (MOVEMENT): +10 % speed, and your slides leave a trail that slows. It works beside Blood Slide's bleed.
  - **Midas** (GOLD): +25 % gold, +25 % pickup range, +10 % luck.
  - **Prodigy** (XP): +15 % XP, +1 reroll, +1 banish.
- The end screen now names what you unlocked and how ("SECRET FOUND", "CHALLENGE COMPLETE") and adds challenge bounties to your Renown.

## Known issues
- **Your old saves:** the Codex can't know which enemies you killed before this version, so it counts every enemy of an arena you've fought in as "seen" (with 0 kills). Evolutions and synergies you found in v0.6.0 weren't recorded either: find them again to fill those pages.
- **Prices and bounties are a first guess** (300 Renown a Boon; a winning run earns about 150–250).
- Sounds are still placeholders made in code, as before.
